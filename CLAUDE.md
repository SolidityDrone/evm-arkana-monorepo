## Project Overview

Arkana is a privacy-preserving DeFi protocol on Ethereum. It uses zero-knowledge proofs (Groth16/Circom2), Merkle tree commitments, and timelock encryption to enable private deposits, withdrawals, and swaps. Built for EthGlobal MoneyHack2026 on Sepolia.

The monorepo has three main workspaces:
- `circom/` — Circom2 circuits and JS test scripts
- `contracts/` — Solidity smart contracts (Foundry)
- `frontend/` — Next.js frontend application

## Architecture

### Zero-Knowledge Circuit System

Six Groth16 circuits handle all private operations: **Entry**, **Deposit**, **Withdraw**, **Send**, **Absorb-Send**, **Absorb-Withdraw**. Each circuit has a corresponding on-chain verifier (auto-generated by SnarkJS, committed to `frontend/public/circuits/`). Proof generation happens client-side so private keys never leave the user's device.

**Merkle tree state**: Each token has its own incremental Merkle tree (`LeanIMTData`) in the `Arkana` contract, using Poseidon2 hashing. Commitments are leaves; nullifiers prevent double-spending.

### Hybrid Pedersen Commitment

The commitment scheme is split between circuit and contract to avoid race conditions on share minting:
1. Circuit computes a partial commitment using private values (secret, nullifier, amount)
2. Contract adds public values (shares amount, unlock time) via Grumpkin curve point addition on-chain
3. Final commitment is stored as a Merkle leaf

### Key Architectural Files

- `contracts/src/Arkana.sol` — Main protocol contract; handles deposits, withdrawals, sends, absorbs
- `contracts/src/ArkanaVault.sol` — ERC4626 vault wrapping Aave aTokens per token
- `circom/main/` — Circom circuit entry points
- `circom/lib/frost/frost_helper.js` — FROST threshold signature helpers (in-progress)
- `frontend/lib/eddsa-circuit.ts` — zkAddress derivation from wallet signature
- `frontend/lib/frost-2fa.ts` — FROST 2FA integration (in-progress)
- `frontend/lib/circuit-utils.ts` — Proof generation utilities wrapping SnarkJS
- `frontend/hooks/` — React hooks for each protocol operation (useDeposit, useWithdraw, useSend…)
- `frontend/providers/` — AccountProvider (zkAddress), AccountStateProvider (nonce/state discovery)


### Privacy Model

- Private balances stored only as Poseidon commitments; amounts never revealed on-chain
- Upfront fees charged at deposit to prevent timing analysis of withdrawals
- Nullifier system (mapping `usedNullifiers`) prevents commitment reuse
- Frontend stores user state in IndexedDB (note history, nonce tracking)
